# Альмагест

**Открыть сайт:** https://quroroyr.github.io/almagest/

Главная астрологического сайта в виде цифровой обсерватории: живое ночное небо,
планеты на орбитах, небесная сфера и армиллярная сфера. Введи дату, время и город рождения,
и страница вычертит натальную карту, сравнит пару и покажет небо на эту минуту.
Положения светил считаются по астрономическим формулам, а не выбираются случайно.

Название рабочее. Цены, имя астролога и контакты не заполнены: на их местах стоят заглушки.

## Что умеет
- **Первый экран**: ночь над террасой обсерватории. Наведи на звезду созвездия —
  появится её имя, блеск и короткая справка, созвездие подсветится. Наведи на Луну —
  она покажет настоящую фазу на сегодня. Щелчок по небу запускает падающую звезду.

- **Живой первый экран**: небо проявляется, по точкам вычерчиваются созвездия Льва
  и Ориона, Луна освещена направленным светом, облака и дымка идут своими слоями.
  Свет и звёздная пыль чуть отзываются на курсор. «Открыть карту» раскрывает звезду
  Регул в круги натальной карты.
- **Вселенная в тебе**: планеты на своих орбитах с настоящим соотношением скоростей.
  При прокрутке камера опускается через туман к долине. Наведи на название, и планета
  подсветится.
- **Небо сегодня**: большая Земля по фотокартам NASA (материки, облака, огни городов,
  атмосфера), повёрнутая по звёздному времени: день и ночь лежат на настоящих странах.
  Вокруг — Солнце, Луна и планеты, каждая в направлении своей настоящей эклиптической
  долготы (орбиты и расстояния — схема), Луна в настоящей фазе, созвездия зодиака,
  Млечный Путь. Таблица светил, карточка Луны, своя шкала суток с отметками, когда Солнце
  и Луна выше всего над городом; «ход времени» прокручивает сутки примерно за полторы минуты.
- **Натальная карта**: церемония построения примерно на три секунды. Сначала световая
  точка, затем круги и градусные риски, знаки, планеты, аспекты и световая волна.
  При пересчёте планеты переезжают на новые места. Если время рождения неизвестно,
  карта строится на полдень, без асцендента и домов.
  Город — любой: поиск по встроенному списку и открытому геокодеру Open-Meteo (уходит только
  название). Местное время переводится по поясу города с историей перевода часов, включая
  летнее время прошлых лет. Готовой картой можно поделиться ссылкой (она сразу открывает
  эту карту) или скачать её картинкой 1080×1350.
- **Расшифровка**: карточки по каждой планете (знак, градус, дом, аспекты). При наведении
  карточка и планета на круге соединяются световой линией.
- **Совместимость**: два силуэта из звёздной пыли и связи между планетами двух людей.
  Процентов «совпадения» нет, только реально посчитанные аспекты.
- **Консультации**: заявка в окне на сайте — уходит астрологу в Telegram (см. «Заявки и контакты»).
- **Как мы считаем**: кабинет обсерватории с армиллярной сферой, методика и её ограничения.
- **Финал**: ночное озеро с отражением неба; комета пролетает один раз.
- Работает на телефоне, уважает настройку «уменьшить движение», без WebGL показывает
  статичный постер, и все расчёты продолжают работать.

## Управление

| Действие | Как |
|---|---|
| Открыть карту с первого экрана | кнопка «Открыть карту» |
| Построить свою карту | заполнить форму и нажать «Построить карту» |
| Связать планету и толкование | навести на планету в круге или на карточку |
| Выделить слой карты | кнопки «Планеты», «Аспекты», «Дома» под кругом |
| Сравнить пару | ввести две даты и нажать «Сравнить» |
| Найти светило в «Небе сегодня» | навести на строку таблицы или на само тело, клик закрепляет |
| Прокрутить время суток | тянуть шкалу внизу (или ← / → на ней, Shift — по часу); «Сейчас» — текущая минута |
| Запустить ход времени | кнопка ▶ у шкалы, повторное нажатие — пауза |
| Сменить город | список в карточке даты справа вверху |

Параметры адреса:

- `?quality=high|medium|low` — зафиксировать уровень качества графики
  (по умолчанию подбирается сам по времени кадра);
- `?gpu` — замер времени сцен на видеокарте (`Stage.gpuStats()` в консоли).

## Как сделано

- Статический сайт без сборки, фреймворков и зависимостей: чистый JavaScript, CSS и GLSL.
- **Графика сцен** — WebGL2 и свои шейдеры (`shaders/`, грузятся при старте). Один общий холст на всю
  страницу, рисуется только видимая часть. Небо, Луна, облака, туман, планеты, небесная
  сфера, вода и комета строятся в реальном времени.
  Карты Земли, планет, колец Сатурна и панорама Млечного Пути — [Solar System Scope](https://www.solarsystemscope.com/textures/)
  (CC BY 4.0, на основе данных NASA); в «Небе сегодня» они ложатся на сферы в шейдере.
  Пейзажи (горы, терраса, долина, берег, кабинет) — отдельные картинки-слои,
  сгенерированные локально нейросетью Z-Image-Turbo (лицензия Apache 2.0) на зелёном
  фоне, увеличенные 4x-UltraSharp и вырезанные с восстановлением цвета края (без каймы).
  Свет, дымку, пылинки и блики на них накладывает шейдер; на телефоне и слабых
  компьютерах грузятся версии 1408 px, на остальных — 2560 px.
- **Круг карты и силуэты** — Canvas 2D.
- **Эфемериды** (`js/astro.js`): орбиты планет с решением уравнения Кеплера и поправками
  на притяжение Юпитера и Сатурна, Луна с двенадцатью главными неравенствами.
  Сверено с эталонными положениями J2000, ошибка до 0,03°. Звёздное время, асцендент,
  середина неба, равные дома, фазы Луны.
- **Созвездия** (`js/stars.js`): 12 зодиакальных и 11 соседних, координаты звёзд и линии фигур.
- Шейдеры компилируются в фоне, есть три уровня качества и автоматическое снижение
  на слабых видеокартах.

## Запуск у себя

Картинки сцен загружаются в WebGL, а браузер не даёт сделать это со страницы,
открытой просто как файл. Поэтому нужен любой локальный сервер, например:

```
git clone https://github.com/Quroroyr/almagest.git
cd almagest
python -m http.server 8000
```

Сайт откроется на http://localhost:8000. Без сервера страница тоже откроется,
но вместо сцен будет статичный постер (браузер не отдаёт шейдеры и картинки в WebGL).
Собирать ничего не нужно: правишь файл — обновляешь страницу.

## Заявки и контакты

Всё, что заполняет владелец сайта, лежит в `js/config.js`:

- `telegram` и `email` — показываются в подвале. Пока обработчика нет, кнопка «Отправить заявку»
  копирует готовый текст заявки и открывает чат в Telegram (или письмо).
- `orderEndpoint` — адрес обработчика: тогда заявка приходит астрологу в Telegram сама.
  Обработчик — `server/telegram-worker.js` для Cloudflare Workers (бесплатного тарифа хватает):
  1. Создать бота у [@BotFather](https://t.me/BotFather), получить токен; написать боту
     любое сообщение и узнать свой `chat_id` по адресу `https://api.telegram.org/bot<токен>/getUpdates`.
  2. В [Cloudflare](https://dash.cloudflare.com) → Workers → Create Worker, вставить код из файла.
  3. В настройках воркера задать `BOT_TOKEN` (как секрет), `CHAT_ID` и `ALLOWED_ORIGIN`
     (`https://quroroyr.github.io`).
  4. Адрес воркера вписать в `orderEndpoint`.

Токен бота остаётся в Cloudflare и на сайт не попадает. В форме есть невидимое поле-ловушка
для спам-ботов и согласие на передачу данных астрологу.

## Структура

```
index.html          разметка страницы
css/main.css        стили
js/config.js        настройки владельца: контакты и адрес обработчика заявок
js/astro.js         эфемериды: планеты, Луна, звёздное время, дома, фазы
js/stars.js         созвездия: координаты звёзд и линии фигур
js/pair-points.js   точки силуэтов для «Совместимости»
js/gl.js            движок сцен: общий холст, виды секций, качество, текстуры
js/app.js           логика страницы: карта, совместимость, «Небо сегодня», интерактив
shaders/            шейдеры сцен (common.glsl — общие функции)
assets/             фото-слои пейзажей, текстуры Земли и планет, постер без WebGL, превью ссылки
server/             обработчик заявок для Cloudflare Workers (на сайте не исполняется)
```
