# Альмагест

**Открыть сайт:** https://quroroyr.github.io/almagest/

Демо-главная сайта астрологических предсказаний в стиле старинного звёздного атласа.
Введи дату, время и город рождения, и страница построит натальную карту, сравнит пару
и покажет небо на эту минуту. Положения светил считаются по астрономическим формулам,
а не выбираются случайно.

Название рабочее. Цены, имя астролога и контакты не заполнены: на их местах стоят заглушки.

## Что умеет

- **Лента зодиака** во всю ширину экрана: созвездия нарисованы акварелью по атласу,
  на них стоят Солнце, Луна и планеты в своих настоящих положениях. Ленту можно тянуть,
  а при наведении на светило показывается подсказка.
- **Натальная карта** по дате, времени и городу рождения (28 городов или свои
  координаты): планеты по знакам и домам, асцендент, середина неба, аспекты и
  ретроградность. Если время рождения неизвестно, карта строится на полдень, без
  асцендента и домов.
- **Расшифровка карты**: при наведении на планету в круге подсвечивается её строка
  в тексте, и наоборот.
- **Совместимость пары** по двум датам рождения: двойной круг, знаки Солнца и Луны
  обоих и связи между их планетами.
- **Небо сегодня**: фаза Луны и таблица светил с положением и направлением движения.
  Пока страница открыта, всё пересчитывается само.
- **Расчёт прямо в браузере**: данные никуда не отправляются, внешних API нет.
- Работает на телефоне, уважает настройку «уменьшить движение».

## Управление

| Действие | Как |
|---|---|
| Прокрутить ленту зодиака | тянуть мышью или пальцем, Shift + колесо |
| Перейти к знаку | кнопка знака на линейке над лентой |
| Сдвинуть ленту с клавиатуры | ← / → при фокусе на ленте |
| Узнать, что за светило | навести курсор на ленту или на круг карты |
| Построить карту | заполнить форму и нажать «Построить моё небо» |
| Сравнить пару | ввести две даты и нажать «Сравнить» (до этого показан пример) |

## Как сделано

- Один HTML-файл: HTML, CSS и чистый JavaScript, без фреймворков и библиотек.
- **Эфемериды** (`astro.js`): орбиты планет с решением уравнения Кеплера и поправками
  на притяжение Юпитера и Сатурна, Луна с двенадцатью главными неравенствами, Плутон
  отдельным рядом. Сверено с эталонными положениями J2000, ошибка до 0,03°.
  Звёздное время, асцендент, середина неба, равные дома, фазы Луны.
- **Созвездия** (`stars.js`): 12 зодиакальных и 11 соседних, координаты звёзд и линии фигур.
- **Графика на Canvas 2D**: процедурная акварель (шум, мокрые края, затёки, зерно
  бумаги), гравированные круги карт, свет от курсора, инерция при перетаскивании.
  Картинок нет, всё на экране рисуется кодом.
- Шрифты из Google Fonts.

## Запуск у себя

Сайт уже собран в `index.html`: его можно просто открыть в браузере.

Исходники лежат в `src/` и в `astro.js`, `stars.js`. После правок пересобрать
`index.html` можно так (нужен [Node.js](https://nodejs.org/) 18 или новее):

```
git clone https://github.com/Quroroyr/almagest.git
cd almagest
node build.js
```
